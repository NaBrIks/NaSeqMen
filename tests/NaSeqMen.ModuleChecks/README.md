# Проверки модулей

Из корня проекта:

```powershell
dotnet run --project tests/NaSeqMen.ModuleChecks/NaSeqMen.ModuleChecks.csproj -c Release --no-launch-profile
```

Проверки работают с собственной подменой клавиатурного выхода и локальным mock OBS WebSocket. Они не вызывают реальный SendInput, не запускают программы и не включают захват ввода. Проверяется только чтение перечня Windows-интерфейсов и наличие процессов; идентификаторы устройств не выводятся.

Проверки клавиатурного выхода охватывают повторные нажатия, общие модификаторы разных источников и соединений, чужие уже удерживаемые клавиши, отмену, ошибку отправки, повтор cleanup и Dispose. Fake-отправитель подтверждает порядок вызовов, но не доказывает аппаратную работу SendInput.

Проверки OBS охватывают авторизацию, команды, параметры, события, корреляцию параллельных запросов, отказ, отсутствие запросов снимка при подключении и вызов нового запроса из обработчика события без взаимной блокировки.

## Отдельная разрешённая проверка реального OBS

```powershell
dotnet run --project tests/NaSeqMen.ModuleChecks/NaSeqMen.ModuleChecks.csproj -c Release --no-build -- --obs-settings local/obs-experiment.json
```

Этот режим читает локальные поля `address` и `password`, подключает настоящий модуль и отправляет только GetVersion, GetSceneList, GetRecordStatus. Он не меняет запись, сцену или звук. Пароль и значения соединения не выводятся. Если запись уже активна, проверка сообщает отказ и не пытается её останавливать. Использовать только для явно выбранного тестового OBS.

2026-11-15: 37 локальных проверок прошли; 4 read-only проверки экспериментального OBS прошли, запись не активна. Физические нажатия, подавление ввода и отправка клавиш Windows этим результатом не подтверждены.
