# Интеграция UI.TechnicalShell

По прямому поручению владельца источник — `C:\Git\UI.TechnicalShell`. Полный стандарт скопирован в [ui-principles.md](ui-principles.md); фактический путь исходного набора исправлен в локальной копии. Исходный набор не изменяется.

NaSeqMen использует HTML/CSS/JavaScript, поэтому Razor-компонент AppShell адаптирован в shell.js и index.html. Палитры, общие стили, варианты границ, локальный шрифт Tabler с лицензией и модуль подсказок переносятся в wwwroot/technical-shell с сохранением исходного содержимого. Копия ресурсов входит в пакет редактора; установленному приложению не нужна исходная папка C:\Git\UI.TechnicalShell. Продуктовая логика остаётся в app.js, forms.js и graph.js.

Сохранены закреплённая шапка, левое сворачиваемое дерево, последнее корневое меню «Настройки» с именами соединений из API и одно меню оформления. Порядок тем: Light, Cream, Emerald, Dark; плотность Nano/Mini/Norm меняет отступы, а не размер основного шрифта. Варианты границ Compact/Rounded/Square и переключатель подсказок находятся в том же меню. По умолчанию Cream/Nano.

Предпочтения оформления, языка, подсказок и меню хранятся только под naseqmen.ui.*. Это настройки самого редактора, а не хранилище событий исполнителя. Локализуется интерфейс RU/EN; пользовательские имена и код C# не переводятся. Данные API получают свои имена от исполнителя.

Подсказки используют общий ui-tooltip.js и data-tooltip, включая фокус, aria-describedby и Escape. Нативные title не дублируют их. Справка больших рабочих блоков открывается по ⓘ в модальном окне; уведомления не создают баннеры и не меняют размеры рабочих областей. Формы и граф используют семантические токены --lu-*.

При обновлении исходного набора сначала читать его AGENTS.md, README.md, REQUIREMENTS.md и docs/integration.md, затем переносить нужные ресурсы и проверять адаптер. Для приёмки обязательны Cream/Nano, тёмная тема, полное меню оформления, RU/EN, дерево, независимая прокрутка, модальные окна и подсказки. Результаты конкретного прогона записываются в [verification.md](verification.md).
