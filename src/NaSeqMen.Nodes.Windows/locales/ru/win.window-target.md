# Фокус на окно

## Назначение

Узел **Фокус на окно** ищет среди видимых окон верхнего уровня Windows окно по имени процесса и/или подстроке заголовка, при необходимости разворачивает и выводит его на передний план, а затем прикрепляет дескриптор (`targetHwnd`) и метаданные (`targetWindow`) к корзине сообщения перед отправкой дальше.

## Типичные сценарии

- **Надёжный ввод текста в конкретную программу:** соедините **Виртуальная кнопка** -> **Фокус на окно** (`found`) -> **Ввод текста (клавиатура)** (`in`). Даже если окно было свёрнуто или перекрыто, оно восстановится и получит фокус перед набором.
- **Тихий поиск окна для фонового ввода:** снимите флажок *Вывести вперёд* (`focus = false`) и подключите `found` -> **Фоновый ввод текста** (`in`), оставив поле *Процесс* в **Фоновом вводе текста** пустым. Узел найдёт окно и передаст `targetHwnd` без переключения фокуса.
- **Проверка, открыто ли приложение:** используйте ветки `found` и `notFound`, чтобы выполнять макрос только при запущенной программе либо выводить предупреждение в **Отладку**.
- **Быстрое переключение на нужное окно:** подключите горячую клавишу или **Виртуальную кнопку**, чтобы мгновенно выводить на передний план нужный терминал, браузер или редактор.

## Порты

### Входы

- **`in` (Сообщение, `Any`)** — входящее сообщение, запускающее поиск окна и (при включённой опции) его активацию.

### Выходы

- **`found` (Найдено, `Any`)** — копия сообщения при успешном поиске (и после паузы `waitAfterFocusMs`, если включено *Вывести вперёд*). Добавляет:
  - `properties["targetHwnd"]` — числовой дескриптор Win32 `HWND` (`long`), автоматически подхватываемый узлом **Фоновый ввод текста**.
  - `properties["targetWindow"]` — объект `{ hwnd, process, title }`.
- **`notFound` (Не найдено, `Any`)** — копия сообщения, если подходящего открытого окна нет (или оба поля фильтра пустые).

## Настройка и советы

- **Процесс (`processName`, по умолчанию: `"notepad"`):** имя процесса с `.exe` или без; сравнение без учёта регистра (точное или по подстроке).
- **Заголовок (`titleContains`, по умолчанию: пусто):** необязательная подстрока заголовка без учёта регистра. Помогает выбрать нужное окно, если у одного процесса открыто несколько окон.
- **Вывести вперёд (`focus`, по умолчанию: `true`):** восстанавливает свёрнутое окно (`SW_RESTORE`) и делает его активным. Отключите, если нужно лишь получить `targetHwnd` для фоновых действий.
- **Пауза фокуса (мс) (`waitAfterFocusMs`, по умолчанию: `40`):** задержка (`0`–`2000` мс) после активации окна перед передачей сообщения дальше. Для тяжёлых Electron-приложений при потере первого символа увеличьте до `80`–`150` мс.
- **Только видимые окна:** свёрнутые на панель задач окна находятся и разворачиваются, а скрытые системные окна и собственный процесс NaSeqMen пропускаются.
