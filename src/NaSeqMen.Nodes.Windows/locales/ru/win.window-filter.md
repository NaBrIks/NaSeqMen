# Фильтр окон

## Назначение

Узел **Фильтр окон** при получении сообщения проверяет текущее активное окно Windows и направляет сообщение либо на выход `match` («Совпало»), либо на `noMatch` («Не совпало») по имени процесса и/или заголовку окна. Дополнительно узел записывает сведения об активном окне в корзину сообщения для последующих скриптов или отладки.

## Типичные сценарии

- **Контекстные горячие клавиши для приложений:** поставьте **Фильтр окон** (например, *Процесс* = `code` или `blender`) после **Ввода с клавиатуры** или узла перехвата, чтобы одна и та же клавиша запускала специализированное действие в редакторе и альтернативное (`noMatch`) в остальных программах.
- **Фильтрация по конкретному документу или вкладке:** укажите одновременно *Процесс* и подстроку *Заголовка* (например, название документа или веб-приложения), чтобы защитить важные команды от случайного срабатывания.
- **Список исключений через «Инвертировать»:** задайте имя процесса игры или видеоплеера и включите *Инвертировать*, чтобы глобальные действия не срабатывали, пока это приложение активно.
- **Выяснение точного имени процесса и заголовка:** пропустите сообщение через **Фильтр окон** в **Отладку** (с включённой *Полной корзиной*), чтобы увидеть точные поля `process` и `title`.

## Порты

### Входы

- **`in` (Сообщение, `Any`)** — любая входящая корзина сообщения.

### Выходы

- **`match` (Совпало, `Any`)** — сообщение, когда активное окно удовлетворяет условию (или не удовлетворяет при включённом *Инвертировать*).
- **`noMatch` (Не совпало, `Any`)** — противоположная ветка маршрутизации.

На оба выхода передаётся копия сообщения со свойством `properties["activeWindow"] = { hwnd, process, title }` (если активное окно определено).

## Настройка и советы

- **Процесс (`processName`, по умолчанию: пусто):** имя процесса с `.exe` или без него (например, `notepad` или `notepad.exe`). Проверяется без учёта регистра по полному совпадению или подстроке.
- **Заголовок (`titleContains`, по умолчанию: пусто):** подстрока заголовка окна без учёта регистра.
- **Совместная работа полей:** если заполнены оба поля, должны совпасть **оба** условия (логическое И). Если **оба** поля пустые, совпадение не происходит (выход `noMatch`, либо `match` при включённом *Инвертировать*).
- **Инвертировать (`invert`, по умолчанию: `false`):** меняет результат проверки на противоположный.
- **Каскадная маршрутизация:** соединяйте выход `noMatch` одного **Фильтра окон** со входом `in` следующего, чтобы построить цепочку условий `если / иначе если / иначе` для нескольких программ.
