# OBS Studio

## Назначение

Узел **OBS Studio** подключается к встроенному серверу WebSocket v5 в OBS Studio (версии 28+) с автоматическим переподключением. Он обеспечивает двустороннее управление сценами, громкостью, заглушением аудиовходов, записью, трансляцией и произвольными командами WebSocket v5, а также передаёт в поток живые уровни VU и события смены состояния. Встроенный виджет показывает статус соединения, версию OBS и позволяет быстро переключать сцены.

## Типичные сценарии

- **Живой микшер прямо на холсте:** подключите **Виртуальный ползунок** (`value`) -> `volume`, **Виртуальную кнопку** (`press`) -> `mute`, заведите `volumeChanged` и `muteChanged` обратно на их входы `set`, а `vuLevel` направьте в **Индикатор уровня (VU)**.
- **Управление сценами и записью по горячим клавишам:** подавайте сигналы на `scene`, `record` или `stream` от **Ввода с клавиатуры** или узлов перехвата, чтобы управлять OBS, не выходя из полноэкранных приложений.
- **Мониторинг нескольких аудиодорожек:** оставьте поле *Аудиовход* пустым, включите *Индикаторы VU* и разведите выход `vuLevel` на несколько узлов **Индикатор уровня (VU)** с разными значениями *Фильтра источника* (например, `Mic/Aux` и `Desktop Audio`).
- **Расширенная автоматизация через сырые запросы:** сформируйте в **C#-функции** объект `{ "requestType": "SetSceneItemEnabled", "requestData": { ... } }`, отправьте его на `command` и обработайте ответ на выходе `status`.

## Порты

### Входы

- **`scene` (Выбрать сцену, `String`)** — переключает текущую программную сцену (`SetCurrentProgramScene`). При пустом `payload` использует параметр *Сцена по умолчанию*.
- **`volume` (Громкость, `Number`)** — устанавливает громкость (`SetInputVolume`) для источника из `properties["inputName"]` (если задано) или из параметра *Аудиовход* в выбранной *Шкале громкости*.
- **`mute` (Заглушить / Перекл., `Any`)** — работает с `properties["inputName"]` или *Аудиовходом*. При явном булевом значении (`true`/`false`) вызывает `SetInputMute`, при любом другом значении (например, `"toggle"`) — `ToggleInputMute`.
- **`record` (Запись, `Any`)** — `true` или `"start"` запускает запись; `false` или `"stop"` останавливает; любое другое значение переключает состояние.
- **`stream` (Трансляция, `Any`)** — `true` или `"start"` запускает трансляцию; `false` или `"stop"` останавливает; любое другое значение переключает состояние.
- **`command` (Сырой запрос, `Object`)** — принимает строку с именем запроса (например, `"GetStats"`) или объект `{ "requestType": "...", "requestData": { ... } }`. Полный ответ публикуется на порте `status`.

### Выходы

- **`vuLevel` (Уровень VU (0..100), `Number`)** — выдаёт пиковый уровень `0..100` (шкала `-60..0 дБ`), `topic = inputName`, в `properties`: `inputName`, `mul`, `db`, `leftPercent`, `rightPercent`.
- **`sceneChanged` (Сцена изменена, `String`)** — имя новой сцены (`topic = "obs.scene"`, `properties.sceneName`).
- **`muteChanged` (Заглушение изменено, `Boolean`)** — состояние `true`/`false` (`topic = inputName`, `properties.inputName`, `properties.inputMuted`).
- **`volumeChanged` (Громкость изменена, `Number`)** — обновлённая громкость в выбранной *Шкале громкости* (`topic = inputName`, `properties`: `inputName`, `mul`, `db`, `percent`).
- **`status` (Статус / Ответ, `Object`)** — события соединения (`obs.connection`), состояния трансляции/записи (`obs.stream`, `obs.record`), ответы на сырые команды (`obs.response`) и ошибки (`obs.error`).

## Настройка и советы

- **Настройка OBS:** в OBS Studio откройте **Инструменты -> Настройки сервера WebSocket**, включите сервер (порт по умолчанию `4455`) и перенесите пароль в поле *Пароль* (`password`).
- **Подключаться (`enabled`, по умолчанию: `true`):** временно снимите флажок, если OBS не запущен и вы хотите отключить попытки переподключения.
- **Хост (`host`, по умолчанию: `"127.0.0.1"`) и Порт (`port`, по умолчанию: `4455`):** поддерживается подключение как к локальному OBS, так и по локальной сети.
- **Аудиовход (`audioSource`, по умолчанию: пусто):** задаёт источник по умолчанию для команд `volume`/`mute` и одновременно фильтрует события `vuLevel`, `muteChanged` и `volumeChanged`. Оставьте пустым, чтобы принимать события от всех источников и указывать `props["inputName"]` в сообщениях при управлении несколькими каналами через один узел.
- **Сцена по умолчанию (`sceneName`, по умолчанию: пусто):** используется, если на вход `scene` приходит пустое сообщение.
- **Индикаторы VU (`subscribeMeters`, по умолчанию: `true`) и Интервал VU (`meterThrottleMs`, по умолчанию: `50`):** отключите `subscribeMeters`, если индикаторы не нужны — это снизит сетевой трафик. Увеличение `meterThrottleMs` (например, до `100` мс) уменьшает нагрузку на интерфейс.
- **Шкала громкости (`volumeScale`, по умолчанию: `"percent"`):**
  - `percent` (`0..100%`) — линейное отображение диапазона `-60..0 дБ` (`0%` устанавливает множитель `0`).
  - `mul` (`Множитель 0..1`) — прямой линейный множитель OBS (на вход допускается `0..20`).
  - `db` (`-60..0 дБ`) — прямая шкала децибел (при `<= -100 дБ` множитель сбрасывается в `0`).
