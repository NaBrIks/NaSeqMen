# Виртуальная кнопка

## Назначение

Узел **Виртуальная кнопка** отображает интерактивную кнопку без фиксации или переключатель прямо на холсте потока. Он позволяет вручную запускать сценарии, собирать виртуальные пульты управления для работы и тестирования, а также синхронизировать индикацию с внешним состоянием через безопасный вход обратной связи `set`.

## Типичные сценарии

- **Кнопка отключения микрофона в OBS с обратной связью:** выберите *Режим* `Переключатель`, укажите *Значение Вкл* = `true` и *Значение Выкл* = `false`. Подключите `press` -> **OBS Studio** (`mute`), а выход **OBS Studio** (`muteChanged`) верните на вход `set` — кнопка будет отражать реальное состояние, даже если звук переключили в самом OBS.
- **Переключение сцены в один клик:** выберите *Режим* `Без фиксации`, задайте *Текст кнопки* `Сцена 1` и *Значение Вкл / Нажатие* `Scene 1`, затем подключите `press` ко входу `scene` узла **OBS Studio**.
- **Удержание (Push-to-Talk):** в режиме `Без фиксации` задайте *Значение Вкл / Нажатие* = `false` (включить звук) и *Значение Выкл* = `true` (заглушить), подключив оба выхода `press` и `release` ко входу `mute` узла **OBS Studio**.
- **Запуск скриптов и текстовых макросов:** подключите `press` к **C#-функции** или **Вводу текста (клавиатура)** для ручного запуска автоматизации.

## Порты

### Входы

- **`set` (Задать состояние, `Boolean`)** — обновляет визуальное состояние (вкл/выкл) без отправки исходящего сообщения, что исключает бесконечные петли. Принимает булевы значения, числа (`0` = выкл, не ноль = вкл) и строки (`"true"`, `"false"`, `"1"`, `"0"`, `"on"`, `"off"`).

### Выходы

- **`press` (Нажатие, `Any`)** — срабатывает при нажатии в режиме `Без фиксации` (отправляет `payload`) или при каждом клике в режиме `Переключатель` (чередуя `payload` при включении и `offPayload` при выключении). Записывает в `properties` ключи `mode`, `state` и `action`.
- **`release` (Отпускание, `Any`)** — отправляет `offPayload` при отпускании кнопки в режиме `Без фиксации` (`properties.action = "release"`, `properties.state = false`). В режиме `Переключатель` не используется.

## Настройка и советы

- **Текст кнопки (`buttonLabel`, по умолчанию: `"Press"`):** надпись на кнопке виджета.
- **Режим (`mode`, по умолчанию: `"momentary"`):**
  - `momentary` (*Без фиксации*) — кнопка активна только пока удерживается; задействованы оба порта `press` и `release`.
  - `toggle` (*Переключатель*) — состояние меняется по каждому клику; оба перехода выходят через `press`.
- **Значение Вкл / Нажатие (`payload`, по умолчанию: `"toggle"`):** автоматически типизируется — `"true"`/`"false"` преобразуются в `bool`, числа — в числовой тип, прочие значения остаются строкой.
- **Значение Выкл (`offPayload`, по умолчанию: `"false"`):** преобразуется по тем же правилам типизации.
- **Тема (`topic`, по умолчанию: `"control.button"`):** значение `topic` в исходящей корзине сообщения.
- **Состояние при старте:** при запуске потока кнопка сбрасывается в выключенное состояние до первого нажатия или сигнала на входе `set`.
