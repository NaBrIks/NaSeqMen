# Ввод с клавиатуры

## Назначение

Узел **Ввод с клавиатуры** пассивно отслеживает события физической клавиатуры в Windows через API Raw Input и отправляет каждое подходящее нажатие в виде корзины сообщения. Работа происходит строго пассивно — исходные нажатия не блокируются и продолжают поступать в активное приложение. Узел также поддерживает кнопку ручного запуска прямо на холсте, чтобы подавать тестовый текст в поток без нажатия физических клавиш.

## Типичные сценарии

- **Глобальный запуск команд для OBS или скриптов:** снимите флажок *Только печатные*, укажите в *Фильтре клавиш* значение `F9, F10` и соедините `out` с узлом **OBS Studio** или **C#-функция**, чтобы реагировать на функциональные клавиши из любого окна.
- **Контекстные реакции по активному окну:** подключите `out` к узлу **Фильтр окон**, чтобы нажатия вызывали действия только тогда, когда на переднем плане находится нужный редактор или инструмент.
- **Быстрое тестирование потока без клавиатуры:** отключите *Перехват клавиатуры*, задайте строку в поле *Тестовый текст* и нажимайте кнопку запуска на узле для проверки дальнейшей цепочки.
- **Диагностика клавиш и модификаторов:** оставьте *Фильтр клавиш* пустым и подключите `out` к узлу **Отладка**, чтобы увидеть имена клавиш, виртуальные коды (`vkCode`) и состояние модификаторов (`shift`, `ctrl`, `alt`).

## Порты

### Входы

У этого узла нет входных портов.

### Выходы

- **`out` (Клавиша / Текст, `String`)** — выдаёт введённый символ (если клавиша печатная) либо имя клавиши (например, `F9`, `Enter`, `Space`).
  - Для событий физической клавиатуры `topic` равен `"keyboard.raw"`, а в `properties` добавляются `source` (`"raw-input"`), `key`, `vkCode`, `printable`, `phase` (`"down"` или `"up"`), `shift`, `ctrl`, `alt`.
  - Для ручного запуска `topic` равен `"keyboard.manual"`, а в `properties` записываются `source` (`"manual-trigger"`) и `nodeTitle`.

## Настройка и советы

- **Перехват клавиатуры (`captureGlobal`, по умолчанию: `true`):** включает глобальное прослушивание Raw Input при запущенном потоке. Отключите, если узел используется только как ручной источник тестовых сообщений.
- **Только печатные (`printableOnly`, по умолчанию: `true`):** отсеивает непечатные клавиши (`Shift`, `Ctrl`, `Alt`, `F1`–`F12`, `Escape`, стрелки). **Снимите этот флажок**, если хотите ловить функциональные или служебные клавиши.
- **Только нажатие (`onlyKeyDown`, по умолчанию: `true`):** игнорирует отпускание клавиши, чтобы одно нажатие порождало одно сообщение. Снимите флажок, если нужно различать фазы `"down"` и `"up"`.
- **Фильтр клавиш (`filterKey`, по умолчанию: пусто):** имена клавиш или символы через запятую без учёта регистра, например `A, Space, F9`. Пустое поле пропускает все клавиши, прошедшие остальные фильтры.
- **Тестовый текст (`testText`, по умолчанию: `"hello world"`):** текст, отправляемый по кнопке ручного запуска.
- **Защита от зацикливания:** текст, отправленный узлом **Ввод текста (клавиатура)**, помечается внутри системы и не возвращается повторно в **Ввод с клавиатуры**.
- **Нужно подавлять или переназначать клавиши?** Данный узел работает только в режиме наблюдения; для перехвата с подавлением используйте узлы модуля Interception.
